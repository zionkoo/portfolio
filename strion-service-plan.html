SOLUTION & REQUIREMENTS

안전한 연결을
실제 기능으로

데이터 흐름과 핵심 기능의 동작 기준을 한 화면에 정리했습니다. 인증이 필요한 요청만 Cloudflare Worker가 대신 처리합니다.

01 · SOURCE

Garmin Connect

Personal API로 최근 러닝 활동 목록과 FIT 원본을 제공합니다.

02 · SECURE LAYER

Cloudflare Worker

API 키를 비밀 환경 변수에 보관하고 허용된 요청만 전달합니다.

03 · WEB SERVICE

STRION

FIT 파싱, 차트, 심박 존, 러닝 다이나믹스와 훈련 해석을 생성합니다.

04 · LOCAL DATA

Browser Storage

원본 FIT와 분석 요약을 사용자 기기에 저장해 날짜로 다시 엽니다.

SECURITY PRINCIPLE

키는 화면에 두지 않습니다

개인 API 키를 HTML·GitHub 저장소·브라우저 저장소에서 분리했습니다. 공개 화면은 Worker 주소만 호출하며, Worker가 Garmin 요청을 중계합니다.

CORE FUNCTIONAL REQUIREMENTS
FR-01연결 상태 확인Worker 응답과 인증 상태를 확인해 연결 성공·실패를 구분해 표시
FR-02최근 활동 동기화최근 러닝 목록을 불러오고 선택한 활동의 FIT 원본을 분석
FR-03중복 저장 방지같은 활동은 기존 기록을 유지하거나 갱신해 중복 카드 생성을 차단
FR-04날짜별 재열람저장 기록을 날짜로 선택해 파일 재업로드 없이 분석 화면 복원
FR-05오류·빈 상태 안내인증 실패, 기록 없음, 네트워크 실패의 원인과 다음 행동을 구분해 안내
GARMIN CONNECT → CLOUDFLARE WORKER → STRION → LOCAL STORAGE
