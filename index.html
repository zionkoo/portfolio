Smart Farm / Applied Example

조원의 제안을 실제 사용 기능으로 연결했습니다.

ICT 담당으로 참여해 재배 담당 조원 2명의 의견을 반영하고, AI 코딩 도구를 활용해 재배일지와 LED 예약 기능을 구현했습니다. 재배일지는 EC·pH 값을 포함한 작업 내용을 수동 메모로 기록하도록 구성했으며, LED는 사용자가 설정한 시각에 자동으로 켜지고 꺼지도록 연결했습니다. 두 기능은 프로젝트 기간 실제 사용되었습니다.
