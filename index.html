Project 02 · Strion

러너가 이해하기 쉬운 FIT 분석 대시보드

Live Demo ↗

Garmin 원본 FIT 파일을 업로드하면 브라우저 안에서 기록을 분석하고 다음 훈련과 레이스 계획까지 연결합니다.

브랜드 의미
STRION은 STRIDE + ON의 합성어입니다. 한 걸음의 데이터를 이해하고 다음 걸음을 이어간다는 의미를 담았습니다.

내 역할
FIT 분석 요구사항, 정보 구조, 레이스·훈련 기능과 모바일 사용 흐름을 정의하고 실제 파일로 반복 검증했습니다.
