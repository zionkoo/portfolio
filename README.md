# Koo Jeongmin | Service Planning Portfolio

문제 정의, 사용 흐름 설계, 기능 요구사항, 실제 환경 검증을 중심으로 구성한 서비스 기획 포트폴리오입니다.

## Pages

- `index.html`: 자기소개, 핵심 역량, 프로젝트 요약, 경력, AI 활용 원칙
- `strion.html`: Garmin FIT 러닝 데이터 서비스 기획 케이스 스터디
- `smart-farm.html`: IoT 모니터링·알림·제어 서비스 기획 케이스 스터디
- `strion-service-plan.html`: Garmin 자동 동기화 서비스 기획서
